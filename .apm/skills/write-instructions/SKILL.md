---
name: write-instructions
description: How to write instructions meant for a model to follow — CLAUDE.md or rules files, skills, agent definitions, system prompts, hook-injected context. Use whenever creating or editing such text.
---

Recent models are capable, and over-detailed instructions make them less adaptable. Write the essentials briefly and leave room for interpretation.

- State the intent and why it matters; trust the model with the details.
- Skip exhaustive lists and rules for edge cases unless a real failure calls for one.
- When adding to existing instructions, merge overlaps rather than appending.
