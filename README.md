# skills

Skills and agents for coding agents.

| Skill | What it does |
|---|---|
| `shorten` | Writes or cuts a document down to the sentences readers need. |
| `human-readable` | Writes and edits technical documents so readers can follow them top to bottom. Written in Japanese. |
| `write-instructions` | Writes instructions for models: CLAUDE.md, skills, agent definitions, prompts. |
| `linus` | Thinks about the task the way Linus Torvalds would. |
| `delegate` | Decides whether to hand a step to the `web-searcher`, `editor`, or `worker` agent. |

## Install

With [APM](https://github.com/microsoft/apm):

```sh
apm install takagiy/skills
```
